# MoneyWise Myanmar — Financial Literacy for Everyone

မြန်မာဘာသာ၊ လက်တွေ့ဘဝဥပမာနှင့် ရိုးရှင်းသောတွက်ချက်မှုများဖြင့် Financial Literacy ကို လူတိုင်းအလွယ်တကူလေ့လာနိုင်သော interactive website ဖြစ်ပါတယ်။

Live ChatGPT Site: https://financial-literacy-workflow.fmgimuzuljb.chatgpt.site

## Main learning workflow

**ရ → စီမံ → သုံး → စု → ကာ → ဆပ် → ပွား → မျှ**

1. ဝင်ငွေရှာ — Earn
2. ငွေကိုစီမံ — Plan
3. သတိရှိစွာသုံး — Spend
4. အနာဂတ်အတွက်စု — Save
5. အန္တရာယ်မှကာကွယ် — Protect
6. အကြွေးကိုစီမံ — Manage Debt
7. အကျိုးရှိစွာပွား — Grow
8. တာဝန်ရှိစွာမျှဝေ — Share Responsibly

## Features

- Interactive eight-step Financial Literacy workflow
- Monthly Budget Calculator
- Emergency Fund Calculator
- Real-world phone purchase Decision Lab
- Profit vs Cash business explanation
- AI Freelancer financial case study
- Ready-to-use 60-minute teaching plan
- Responsive mobile and desktop UI
- Religion-neutral and inclusive content
- No API key, database or backend required

## Run locally

Requirements: Node.js 22 or newer.

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Production build

```bash
npm run build
npm run preview
```

The static production files are generated in `dist/`.

## Privacy

Calculator values stay inside the browser state. The website does not transmit or store bank accounts, card numbers, passwords, PINs or financial credentials.
